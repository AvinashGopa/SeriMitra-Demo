# SeriMitra – Field Photo Collection (Demo)

Demo version of the **SeriMitra Field Collection** Android app, for collecting
real field photographs of silkworm and mulberry. Available in English,
Telugu and Kannada.

**Download page:** https://avinashgopa.github.io/SeriMitra-Demo/

**Direct download (Android APK):**
https://github.com/AvinashGopa/SeriMitra-Demo/releases/download/demo-v1.0.0/app-debug.apk

## Install

1. Download the APK on an Android phone.
2. Open it. If asked, allow *Install unknown apps* for your browser or file manager.
3. Tap **Install**, then **Open**.

## Note

This is a demo build for testing only. A future official release may need to be
installed fresh (uninstall the demo first, after all photos show *All photos sent*).

This repository contains only the download page; the app source code is not published here.
