How to install

  1. Tap Download for Android and wait for the download to finish.
  2. Open the downloaded file (app-debug.apk).
  3. If Android asks, allow Install unknown apps for your browser or file manager.
  4. Tap Install, then Open.
  5. Choose your language (English, తెలుగు, ಕನ್ನಡ), enter your details, and start taking photos.
